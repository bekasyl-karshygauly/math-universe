# Math Universe exploratory design system

Product: interactive mathematics learning for Russian/Kazakh/English learners. Real directions: Basics (numbers/functions/trig/logarithms), Algebra (quadratic/systems/inequalities), Calculus, Linear Algebra, Probability/Statistics. Features: 3-depth lessons, visual demonstrations, quizzes, calculator, plots/3D, notes. Default guest state has zero progress; avoid fake achievements/testimonials.

Current baseline: faithfully reproduce actual source, dark Geist UI with indigo-purple-cyan hero, emoji cards, header plus horizontal tabs.

User-authorized rebrand exploration: three separate systems below. Do not mix systems. Russian visible content, readable Cyrillic type. Keep infinity brand symbol and Math Universe name; source has no image-based logo. No stock business imagery. Primary action starts a lesson. Show real mathematical artifacts.

JOURNAL: white #ffffff, ink #171c27, muted #606672, vermilion #c63d2e, line #dbdce0. Golos Text body; Literata Cyrillic editorial display; IBM Plex Mono utility. An asymmetric contemporary science magazine, red oversized formula/typography art, generous whitespace, fine restrained dividers, squared controls. No beige/terracotta lifestyle mood, no generic card grid.

SCULPTURE: pale lavender #f0eff5, white #ffffff, ink #262239, muted #696178, violet #5741bd, coral #e5a593. Manrope Cyrillic display/body; IBM Plex Mono utility. Gallery-like art direction, giant violet matte sculptural mathematical knot/torus as the singular hero, inset white navigation, off-centre typographic composition, dark plum crisp action, selective 20px corners. No blue-purple-cyan gradients, no glassmorphism, no emoji tiles.

MAP: white #ffffff, forest #164b43, canvas #eef4f1, muted #5c7168, mint #c8e1d5, gold #f1cb67. Golos Text display/body; IBM Plex Mono utility. Learning workspace organised as a meaningful prerequisite map, organic but precise course connections and lesson nodes; left context rail, spacious map with start node selected, right/bottom lesson detail. Restrained shadows/radii 10px. No fake streaks or XP; credible guest onboarding.

All alternatives: 1440 desktop, responsive mobile composition, one dominant action, no horizontal overflow, visible focus, reduced motion. Graphic Design art direction: each variant has a single coherent signature visual built from mathematics, with all text in editable HTML. Design Partner critique: show the learning job immediately; avoid equal-emphasis controls, generic AI patterns and decorative metrics.
